    What this mongosh subset understands

    db.<collection> with find, findOne, aggregate, countDocuments, estimatedDocumentCount, distinct, insertOne, insertMany, updateOne, updateMany, replaceOne, deleteOne, deleteMany, createIndex, getIndexes, dropIndex, dropIndexes, drop; cursor .sort .limit .skip .project .explain() .toArray(); show collections, db.getCollectionNames(), db.getCollection('x'), db.createCollection(name, options).

    Arguments are JavaScript literals: unquoted keys, single or double quotes, trailing commas, comments, ISODate(...), new Date(...), NumberDecimal(...), ObjectId(...), NumberInt, NumberLong, /regex/i, true, false, null. Not supported: variables, functions, arithmetic, loops, use.
